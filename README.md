# Dnyaneshwar Bhandari - Portfolio Website

A modern, responsive portfolio website showcasing my skills and experience as an AWS Cloud/DevOps Engineer.

## Features

- **Dark Theme**: Sleek dark gradient background with glassmorphism effects
- **Responsive Design**: Mobile-friendly layout that adapts to all screen sizes
- **Smooth Navigation**: Sticky header with smooth scrolling to sections
- **Interactive Elements**: Hover effects and mobile navigation toggle
- **Professional Sections**:
  - Hero with profile photo and call-to-action buttons
  - About Me with detailed bio and core competencies
  - Experience showcasing current role
  - Education background
  - Contact information with clickable links

## Technologies Used

- **HTML5**: Semantic markup for structure
- **CSS3**: Custom properties, gradients, flexbox, and grid layouts
- **JavaScript**: Smooth scrolling and mobile menu functionality

## Sections

1. **Home**: Introduction with name, title, and navigation buttons
2. **About**: Personal bio and core competencies in AWS, DevOps, and more
3. **Experience**: Current role at Fortune Cloud Technologies
4. **Education**: B.Sc. Computer Science from Savitribai Phule Pune University
5. **Contact**: Phone, email, LinkedIn, and GitHub links

## How to View

The website is a static site that can be opened directly in any modern web browser.

### Local Development

1. Clone or download the project files
2. Open `index.html` in your web browser
3. For a local server (optional):
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`
